## Проекты

### [Car Analytics Pipeline](https://github.com/htlaets/car-analytics-pipeline)

Воспроизводимый ETL-конвейер обработки автомобильных данных.

- PySpark-преобразования и модель данных «звезда»;
- оркестрация в Apache Airflow;
- слои `raw → staging → core → marts`;
- PostgreSQL/Greenplum, проверки качества и идемпотентная загрузка;
- локальный запуск через Docker Compose;
- тесты и CI в GitHub Actions.

`PySpark` `Airflow` `PostgreSQL` `Greenplum` `Docker` `Data Quality`

### [Olist E-Commerce Analytics](https://github.com/htlaets/Olist_postgresql)

Проектирование и анализ PostgreSQL-хранилища на данных маркетплейса: около 100 тысяч заказов и 9 связанных таблиц.

- схема данных, загрузка и валидация;
- CTE, оконные функции и материализованные представления;
- индексы и оптимизация с `EXPLAIN ANALYZE`;
- RFM-сегментация, когортный и ABC-анализ.

`PostgreSQL` `SQL` `Data Modeling` `Query Optimization`

### [ElectroMarket Analytics](https://github.com/htlaets/electromarket-analytics)

Полный цикл обработки и анализа данных интернет-магазина: Python, SQL, SQLite и Power BI.

`Python` `pandas` `SQL` `SQLite` `Power BI`
